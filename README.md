## Описание приложения:

> Приложение представляет собой реализацию CRUD операций на основе списка покупок в магазине, в которой возможно
> производить добавление, удаление, изменение и чтение покупок.

## Информация о приложении:

- Java 17;
- Приложение разработано с использованием Spring Boot;
- Использован сборщик пакетов Maven;
- Database: PostgreSQL;
- Использована библиотека Liquibase: при запуске создается таблица "shopping_list".
